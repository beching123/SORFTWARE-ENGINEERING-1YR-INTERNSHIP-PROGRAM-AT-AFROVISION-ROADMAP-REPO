2. RAM / System Memory (Dynamic, up to 50%)
WSL 2 runs on a lightweight virtual machine, so its RAM usage changes dynamically based on what you are doing:

When Idle: It uses about 1 GB to 1.5 GB of RAM.

Under Heavy Use: By default, Windows allows WSL 2 to use up to 50% of your total system RAM (or 8 GB, whichever is lower) when compiling big projects or running heavy tasks.

When Closed: When you shut down WSL (or shut down your PC), it frees up all the RAM immediately.

How to Cap WSL's RAM Usage (Optional)
If you have 8 GB of RAM on your PC and don't want WSL using up to 4 GB, you can restrict it easily:

I mentioned Wi-Fi hacking because it is usually the first thing people try when learning penetration testing, and it highlights a major hardware limitation of WSL.

While getting free internet is a common motivation for beginners, Wi-Fi security auditing in professional ethical hacking goes far beyond just cracking a router password for free data.

What Wi-Fi Hacking Actually Involves in Professional Security
In real-world security audits, Wi-Fi testing evaluates how easily an attacker can breach a company's internal perimeter from outside the building.

Traffic Interception (Man-in-the-Middle): If an attacker gains access to a Wi-Fi network (or sets up a fake "Evil Twin" network mimicking a public Wi-Fi spot), they can capture unencrypted traffic, steal login credentials, and intercept sensitive session tokens.

Bypassing Corporate Firewalls: Physical security usually stops an attacker at the front door. However, Wi-Fi signals travel through walls. Cracking a company's Wi-Fi allows an attacker sitting in a car in the parking lot to land directly inside the private corporate network, completely bypassing edge firewalls.

Rogue Access Points: Ethical hackers check if unauthorized wireless routers are plugged into corporate ethernet ports, which create hidden entry points for attackers.

Network Segmentation Audits: Security teams test whether a guest Wi-Fi network is properly isolated from internal servers holding financial, employee, or customer data.

Why People Start with Wi-Fi Hacking
Wi-Fi auditing (using tools like Aircrack-ng) is popular for beginners because:

It deals with immediate, real-world signals around you.

It clearly demonstrates key concepts like handshakes, packet capture, and hash cracking.

However, because these tools require controlling the physical radio frequencies of your Wi-Fi card (putting it into Monitor Mode to capture packets out of the air), WSL cannot do it. WSL runs on a virtual network layer that hides the physical radio hardware.
